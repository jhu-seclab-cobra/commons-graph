# commons-graph

> A Kotlin/JVM directed property graph library with typed entities, Storage backends and label-based visibility.

## Instructions for Agents

- Read the relevant API page before constructing a Graph, Entity or Storage.
- Construct bound entities through Graph factory methods.
- Configure graph identity, entity factories and optional Label hierarchy as the Graph API requires.
- Choose a Storage implementation for the caller’s persistence and concurrency requirements.
- Use `StorageAccess(LayeredStorageImpl())` for guarded `GraphReader`/`GraphWriter` capabilities and fixed `IValue` compatibility snapshots.
- Consult [Storage design](design-storage.md#typed-storage-capabilities) for registered primitive/immutable payloads and scoped cell readers that remain unimplemented.
- Never put language-specific analysis policy in this library.

# Entities

> Graph entities (nodes, edges) with storage-backed typed property access.

## Quick Start

```kotlin
import edu.jhu.cobra.commons.graph.IEntity
import edu.jhu.cobra.commons.value.StrVal

fun setColor(entity: IEntity): StrVal? {
    entity["color"] = StrVal("red")
    return entity["color"] as? StrVal
}
```

## API

### `IEntity` (sealed interface)

- **`val id: String`** -- For nodes: user-provided `NodeID`. For edges: display string `"$src-$tag-$dst"`; use the `(srcNid, dstNid, eTag)` triple for identity because delimiters can occur in components.
- **`val type: IEntity.Type`** -- Entity type information. `IEntity.Type` has `val name: String`.
- **`operator get(name: String): IValue?`** -- Retrieve property. Returns `null` if absent.
- **`operator set(name: String, value: IValue?)`** -- Set property. Pass `null` to remove.
- **`operator contains(name: String): Boolean`** -- Check property existence.
- **`fun asMap(): Map<String, IValue>`** -- Snapshot of all properties.
- **`fun update(props: Map<String, IValue?>): Unit`** -- Bulk update. `null` values remove properties.

### `AbcEntity` (sealed class, implements `IEntity`)

- **`inline fun <reified T : IValue> getTypeProp(name: String): T?`** -- Type-safe property retrieval. Returns `null` on type mismatch.
- **`protected inline fun <reified T : IValue> EntityProperty(optName: String? = null, default: T): ReadWriteProperty<IEntity, T>`** -- Delegate for non-nullable typed property with default.
- **`protected inline fun <reified T : IValue?> EntityProperty(optName: String? = null): ReadWriteProperty<IEntity, T?>`** -- Delegate for nullable typed property.
- **`protected inline fun <reified T : IEntity.Type> EntityType(optName: String? = null, default: T): ReadWriteProperty<IEntity, T>`** -- Delegate for enum-based `IEntity.Type` property.

### `AbcNode` (abstract class, extends `AbcEntity`)

- **`val nodeId: NodeID`** -- User-provided node identifier (same as `id`).
- **`val storageId: Int`** -- Internal storage ID. Do not use in graph-level code.
- **`abstract val type: AbcNode.Type`** -- Node type. Subclasses implement `AbcNode.Type` as an enum.
- **`fun doUseStorage(target: IStorage): Boolean`** -- Check if node is bound to a specific storage.

### `AbcEdge` (abstract class, extends `AbcEntity`)

- **`val srcNid: NodeID`** -- Source node ID.
- **`val dstNid: NodeID`** -- Destination node ID.
- **`val eTag: String`** -- Edge tag.
- **`val storageId: Int`** -- Internal storage ID. Do not use in graph-level code.
- **`val labels: Set<Label>`** -- Visibility labels, including any implied labels. Use `graph.setLabels(edge, edge.storedLabels + label)` to update stored labels.
- **`abstract val type: AbcEdge.Type`** -- Edge type. Subclasses implement `AbcEdge.Type` as an enum.

## Configuration

- Create bound Entities through a Graph; entity subclasses supply their type and optional property delegates.
- Set delegate defaults in the subclass; the example operation accepts an already bound `IEntity`.

## Gotchas

- Never instantiate `AbcNode` or `AbcEdge` subclasses directly. The graph layer calls `bind()` to inject storage and identity.
- `AbcNode` filters reserved properties (`__nid__`, `__owners__`) from all user-facing APIs (`get`, `set`, `contains`, `asMap`, `update`). Setting a reserved property raises `IllegalArgumentException`.
- `AbcNode.equals` compares by `NodeID`. `AbcEdge.equals` compares by `(srcNid, dstNid, eTag)` triple.
- `EntityType` delegate persists the enum name as a `StrVal` property. Renaming enum entries breaks deserialization.
- `EntityProperty` nullable delegate propagates `null` to `IEntity.set(name, null)`, which removes the property.
- Property reads and writes go directly to storage. No local caching in the entity object.
- Each `entity["key"]` read and write is atomic on a thread-safe storage. A read-modify-write is not: wrap `entity["n"] = next(entity["n"])` in `graph.storage.criticalSection { }`.
# Graph & Base Classes

> Typed directed graph API with abstract base classes for multi-edge and simple-edge graphs.

## Quick Start

```kotlin
import edu.jhu.cobra.commons.graph.IGraph

fun connect(graph: IGraph<*, *>): String {
    graph.addNode("a")
    graph.addNode("b")
    return graph.addEdge("a", "b", "calls").id
}
```

## API

### `IGraph<N : AbcNode, E : AbcEdge>`

- **`val nodeIDs: Set<NodeID>`** -- All node IDs in the graph.
- **`addNode(withID: NodeID): N`** -- Create a node under the canonical text of `withID` (the `core` of `StrVal(withID)`); two texts that stand for the same bytes are one node ID, and a lookup by either finds the node. Raises `EntityAlreadyExistException` if ID exists.
- **`claimNode(from: NodeIdentity): N`** — Registers an existing storage row without allocating a row; raises `EntityNotExistException` for a missing row.
- **`readNode(from: NodeIdentity): N`** — Reads an existing row without claiming it; raises `IllegalArgumentException` for absent or mismatched identity.
- **`resolveNodeId(storageId: Int): NodeID?`** — Returns a registered application identifier or null.
- **`getNode(whoseID: NodeID): N?`** -- Retrieve a node by ID. Returns `null` if absent.
- **`containNode(whoseID: NodeID): Boolean`** -- Check node existence.
- **`delNode(whoseID: NodeID): Unit`** -- Delete a node and all incident edges.
- **`getAllNodes(doSatisfy: (N) -> Boolean = { true }): Sequence<N>`** -- Snapshot sequence of nodes, optionally filtered.
- **`addEdge(src: NodeID, dst: NodeID, tag: String): E`** -- Create an edge. Raises `EntityNotExistException` if nodes missing, `EntityAlreadyExistException` if edge exists.
- **`getEdge(src: NodeID, dst: NodeID, tag: String): E?`** -- Retrieve an edge. Returns `null` if absent.
- **`containEdge(src: NodeID, dst: NodeID, tag: String): Boolean`** -- Check edge existence.
- **`delEdge(src: NodeID, dst: NodeID, tag: String): Unit`** -- Delete an edge.
- **`getAllEdges(doSatisfy: (E) -> Boolean = { true }): Sequence<E>`** -- Snapshot sequence of edges, optionally filtered.
- **`getIncomingEdges(of: NodeID): Sequence<E>`** -- All incoming edges to a node.
- **`getOutgoingEdges(of: NodeID): Sequence<E>`** -- All outgoing edges from a node.
- **`getIncomingEdges(of: NodeID, group: String): Sequence<E>`** -- Incoming visible edges in the requested Tag group.
- **`getOutgoingEdges(of: NodeID, group: String): Sequence<E>`** -- Outgoing visible edges in the requested Tag group.
- **`getIncomingEdges(of: NodeID, groups: Set<String>): Sequence<E>`** -- Incoming visible edges selected by any requested Tag group.
- **`getOutgoingEdges(of: NodeID, groups: Set<String>): Sequence<E>`** -- Outgoing visible edges selected by any requested Tag group.
- **`getChildren(of: NodeID, edgeCond: (E) -> Boolean = { true }): Sequence<N>`** -- Direct successors via outgoing edges.
- **`getParents(of: NodeID, edgeCond: (E) -> Boolean = { true }): Sequence<N>`** -- Direct predecessors via incoming edges.
- **`getDescendants(of: NodeID, edgeCond: (E) -> Boolean = { true }): Sequence<N>`** -- BFS transitive successors.
- **`getAncestors(of: NodeID, edgeCond: (E) -> Boolean = { true }): Sequence<N>`** -- BFS transitive predecessors.

### `AbcMultipleGraph<N, E>` (implements `IGraph` and `GraphMergeLaws`)

- **`abstract val storage: IStorage`** -- Graph data storage backend.
- **`protected abstract fun newNodeObj(): N`** -- Factory for an unbound node instance.
- **`protected abstract fun newEdgeObj(): E`** -- Factory for an unbound edge instance.
- **`protected open fun isEdgeVisible(edge: E): Boolean`** -- Declare enumerated edge visibility here; do not hide edges in whole-adjacency overrides.
- **`protected fun rebuild()`** -- Restore graph caches from storage: registers the nodes whose owner set holds this graph's ID.

### `GraphMergeLaws` (implemented by `AbcMultipleGraph`)

- Merge declarations accept prospective writer changes as `WriterChange(before, after)`; null denotes an absent property, and invoking a declaration writes no Storage.

- **`nodePropertyLaw(name: String): PropertyMergeLaw`** -- Node ID property immutable, owner set by union, other names `PropertyMergeLaw.EQUAL_OR_FAIL`.
- **`edgePropertyLaw(name: String): PropertyMergeLaw`** -- Labels by the label merge law (`model.md` Merge Laws), other names `EQUAL_OR_FAIL`.
- **`edgeUniqueKeys(edge: EdgeKey): Map<String, List<String>>`** -- Declared unique keys besides the triple; default none. Override to declare.
- **`coalesceEdges(additions: Collection<EdgeKey>, present: Collection<EdgeKey> = emptyList()): Set<EdgeKey>`** -- Coalesces by `(src, dst, tag)` and validates declared keys.
- **`PropertyMergeLaw.merge(base: IValue?, changes: Collection<PropertyChange>): IValue?`** -- Merged value or `MergeConflictException`; the result never depends on writer order.

### `AbcSimpleGraph<N, E>` (extends `AbcMultipleGraph`)

- **`addEdge(src: NodeID, dst: NodeID, tag: String): E`** -- Raises `EntityAlreadyExistException` if a visible edge from `src` to `dst` exists, regardless of tag.
- The labeled `addEdge` overload requires `PosetTrait`; the same one-visible-edge-per-direction constraint applies.
- **`edgeUniqueKeys(edge: EdgeKey): Map<String, List<String>>`** -- Declares the `(src, dst)` pair as a unique key, so `coalesceEdges` fails for two distinct edges on one pair.

## Configuration

- Supply a unique `graphId: String`, an `IStorage` and the two entity factories in an `AbcMultipleGraph` subclass; construction is shown in [Graph design](../design-graph.md#caller-examples).
- Override `isEdgeVisible` to narrow full/grouped adjacency, all-edge reads and restored-edge resolution; read only fixed edge fields, introduce no side effect and never traverse adjacency. Whole-adjacency overrides do not declare visibility.
- Supply `poset: IPoset` and `labelIndex: LabelEdgeIndex<E>` when implementing `PosetTrait`; construct them as shown in [Label design](../design-label.md).

## Gotchas

- Enumerated edges have both endpoints registered and pass `isEdgeVisible`; caller predicates see only those edges. Exact-tag CRUD retains complete-triple identity even for a hidden edge. Selected queries preserve full directional encounter order.
- `NodeID` is a `String` typealias. Callers provide node IDs; the graph manages internal `Int` storage IDs.
- `delNode` cascades to all incident edges. No orphan edges remain.
- `AbcSimpleGraph` enforces one visible edge per direction per node pair. The `tag` distinguishes the edge but the constraint is on `(src, dst)`.
- `addEdge` with `Label` on `AbcMultipleGraph` is additive -- calling with the same `(src, dst, tag)` appends the label, not replaces.
- `rebuild()` must be called after re-opening a previously populated storage to restore in-memory indexes.
- `AbcMultipleGraph` queries returning `Sequence` return a snapshot taken at the call. Later writes do not change which entities it yields. Label-filtered `PosetTrait` queries are lazy (see [Label API](label.md)).
- On a thread-safe storage, individual Graph and Label hierarchy operations are atomic; labeled traversal sequences are lazy and their whole iteration is not. A group of calls is not atomic: wrap `if (!graph.containNode(id)) graph.addNode(id)` and every other check-then-act in `graph.storage.criticalSection { }`.
- Entities in a snapshot read storage live. On an entity that another thread has deleted, property access raises `EntityNotExistException`.
- Share a graph across threads only when its storage is thread-safe (`graph.storage.criticalSectionLock != null`); its Label hierarchy Storage must be thread-safe or externally synchronized. Concurrent-use constraints: [Storage Gotchas](storage.md#gotchas).

# Label hierarchy

> Label hierarchy and label-selected edge queries.

## Quick Start

```kotlin
import edu.jhu.cobra.commons.graph.AbcEdge
import edu.jhu.cobra.commons.graph.poset.Label
import edu.jhu.cobra.commons.graph.poset.PosetTrait

fun directEdges(graph: PosetTrait<*, *>, label: Label): List<AbcEdge> =
    graph.getLabeledEdges(label).toList()
```

## API

### `Label` (inline value class)

- **`Label(core: LabelID)`** -- Create from string; the label keeps the canonical text of `core`, so two texts that stand for the same bytes are one label. `LabelID` is a `String` typealias.
- **`Label(strVal: StrVal)`** -- Create from `StrVal`.
- **`val core: LabelID`** -- The underlying string identifier.
- **`Label.INFIMUM: Label`** -- Greatest lower bound. Below all labels in the Label hierarchy.
- **`Label.SUPREMUM: Label`** -- Least upper bound. Above all labels in the Label hierarchy.

### `IPoset` (interface)

- **`val allLabels: Set<Label>`** -- All registered labels, including `Label.INFIMUM` and `Label.SUPREMUM`.
- **`fun getParents(label: Label): Map<String, Label>`** -- Named parent labels.
- **`fun setParents(label: Label, parents: Map<String, Label>): Unit`** -- Replace all parents for a label.
- **`fun getAncestors(label: Label): Sequence<Label>`** -- All transitive ancestors through the parent hierarchy.
- **`fun compare(a: Label, b: Label): Int?`** -- Compare in hierarchy. Positive if `a > b`, negative if `a < b`, `0` if equal, `null` if incomparable.

### `PosetTrait<N, E>` (interface, extends `IGraph`)

- Labeled writes, direct-carrier queries and relabel/copy operations are atomic on thread-safe Storage; synchronize a full lazy iteration explicitly.

- **`fun addEdge(src: NodeID, dst: NodeID, tag: String, label: Label): E`** -- Creates or reuses an Edge and assigns the `Label`.
- **`fun delEdge(src: NodeID, dst: NodeID, tag: String, label: Label): Unit`** -- Remove label; delete edge if removing that label leaves no stored labels. An absent label is a no-op.
- **`fun getOutgoingEdges(of: NodeID, label: Label, cond: (E) -> Boolean = { true }): Sequence<E>`** -- Label-filtered outgoing edges.
- **`fun getIncomingEdges(of: NodeID, label: Label, cond: (E) -> Boolean = { true }): Sequence<E>`** -- Label-filtered incoming edges.
- **`fun getChildren(of: NodeID, label: Label, cond: (E) -> Boolean = { true }): Sequence<N>`** -- Nodes via label-filtered outgoing edges.
- **`fun getParents(of: NodeID, label: Label, cond: (E) -> Boolean = { true }): Sequence<N>`** -- Nodes via label-filtered incoming edges.
- **`fun getDescendants(of: NodeID, label: Label, cond: (E) -> Boolean = { true }): Sequence<N>`** -- BFS via label-filtered edges.
- **`fun getAncestors(of: NodeID, label: Label, cond: (E) -> Boolean = { true }): Sequence<N>`** -- BFS via label-filtered edges.
- **`fun getLabeledEdges(label: Label): Sequence<E>`** -- Edges that directly carry `label` (no Label hierarchy covering). Assignments must use the owning Graph’s label operations.
- **`fun relabel(from: Label, to: Label, cond: (E) -> Boolean = { true }): Unit`** -- On every edge carrying `from` that satisfies `cond`, replace `from` with `to`. No-op when `from == to`.
- **`fun copyLabel(from: Label, to: Label, since: Long = 0L, cond: (E) -> Boolean = { true }): Long`** -- Add `to` beside `from` on every edge carrying `from` that satisfies `cond` and was recorded under `from` after record `since`; no label is removed. Returns the record count: pass it as `since` to the next copy of `from` so that copy reads only the edges recorded under `from` in between. No-op when `from == to`.
- **`PosetTrait.mergeLabels(base: Set<Label>, changes: Collection<WriterChange<Set<Label>>>): Set<Label>`** -- Pure merge under the label merge law (`model.md` Merge Laws); `MergeConflictException` under that law's conflict rule.

- **`fun setLabels(edge: E, labels: Set<Label>): Unit`** — Replaces stored labels; an empty set keeps the Edge without a label.
- **`fun visitLabeledEdgesSince(label: Label, since: Long = 0L, visit: (E) -> Label?): Long`** — Visits current carriers recorded after the cursor and records each callback’s contributed label; returns the resulting cursor.

### Edge Visibility Rules

- An edge is visitable under label `by` if at least one of its labels `l` satisfies `by == l` or `by > l` in the Label hierarchy.
- `Label.SUPREMUM` disables label filtering -- all edges pass.
- `Label.INFIMUM` is below all labels -- an edge carrying it is visible under every label; as a query label it matches only the edges carrying it.
- Edges with no labels are visible only when no label filter is applied.

## Configuration

- Construct `Label(core: String)` with the required identifier.
- Construct `PosetDftImpl(storage: IStorage)` with separate Storage for the Label hierarchy.
- Supply `poset` and `labelIndex` on a Graph implementing `PosetTrait`; the operation above accepts that configured Graph.

## Gotchas

- Never assign `Label.SUPREMUM` to edges. It is a structural bound for the Label hierarchy.
- `setParents` replaces all parents. Merge with existing parents if appending: `poset.setParents(label, poset.getParents(label) + mapOf("new" to parentLabel))`.
- `compare` returns `null` for incomparable labels. Always handle the `null` case.
- Edge labels change only through `addEdge`/`delEdge`/`relabel`/`copyLabel`/`setLabels` (the `storedLabels` setter is internal; `labels` is read-only). Label writes through generic property `set`, direct Storage writes or another Graph instance are not observed by the owning Graph’s label operations.
- Never reuse a graph instance after `storage.clear()`: storage IDs restart and the index is not reset.
- Label-filtered `getOutgoingEdges`, `getIncomingEdges`, `getChildren`, `getParents`, `getDescendants`, and `getAncestors` are lazy. The underlying storage calls are individually atomic on thread-safe storage; label filtering and the whole iteration are not one atomic operation. Collect a list before modifying the graph mid-iteration. While other threads write, collect it inside the critical section: `graph.storage.criticalSection { graph.getDescendants(id, label).toList() }`. Keep the Label hierarchy unchanged during traversal, or synchronize its writers with the same enclosing critical section.
# Storage Backends

> Pluggable graph storage with auto-generated Int IDs, property management, and adjacency queries.

## Quick Start

```kotlin
import edu.jhu.cobra.commons.graph.storage.NativeStorageImpl
import edu.jhu.cobra.commons.value.IntVal
import edu.jhu.cobra.commons.value.strVal

val storage = NativeStorageImpl()
val nodeA = storage.addNode(mapOf("name" to "foo".strVal))
val nodeB = storage.addNode()
val edgeId = storage.addEdge(nodeA, nodeB, "calls")
storage.setEdgeProperties(edgeId, mapOf("weight" to IntVal(5)))
```

## API

### `IStorage` (extends `Flushable`)

**Node Operations**

- **`val nodeIDs: Set<Int>`** -- All node IDs.
- **`containsNode(id: Int): Boolean`** -- Check node existence.
- **`addNode(properties: Map<String, IValue> = emptyMap()): Int`** -- Create node, return auto-generated ID.
- **`getNodeProperties(id: Int): Map<String, IValue>`** -- All properties. Raises `EntityNotExistException` if absent.
- **`getNodeProperty(id: Int, name: String): IValue?`** -- Single property. Returns `null` if property absent.
- **`setNodeProperties(id: Int, properties: Map<String, IValue?>): Unit`** -- Update properties. `null` values delete the property.
- **`deleteNode(id: Int): Unit`** -- Delete node and all incident edges.

**Edge Operations**

- **`val edgeIDs: Set<Int>`** -- All edge IDs.
- **`containsEdge(id: Int): Boolean`** -- Check edge existence.
- **`addEdge(src: Int, dst: Int, tag: String, properties: Map<String, IValue> = emptyMap()): Int`** -- Create edge, return auto-generated ID. Raises `EntityNotExistException` if endpoints missing.
- **`getEdgeStructure(id: Int): EdgeStructure`** -- Returns `EdgeStructure(src: Int, dst: Int, tag: String)`.
- **`getEdgeProperties(id: Int): Map<String, IValue>`** -- All properties.
- **`getEdgeProperty(id: Int, name: String): IValue?`** -- Single property.
- **`setEdgeProperties(id: Int, properties: Map<String, IValue?>): Unit`** -- Update properties. `null` values delete.
- **`deleteEdge(id: Int): Unit`** -- Delete an edge.

**Adjacency**

- **`getIncomingEdges(id: Int): Set<Int>`** -- Incoming edge IDs to a node.
- **`getOutgoingEdges(id: Int): Set<Int>`** -- Outgoing edge IDs from a node.

- **`val tagGroup: (String) -> String`** -- Constructor-fixed pure mapping of a complete immutable tag to its Tag group; default identity.
- **`getIncomingEdges(id: Int, group: String): Set<Int>`** -- Copies selected IDs in full directional encounter order; raises `EntityNotExistException` for a missing node.
- **`getOutgoingEdges(id: Int, group: String): Set<Int>`** -- Copies selected IDs in full directional encounter order; raises `EntityNotExistException` for a missing node.
- **`getIncomingEdges(id: Int, groups: Set<String>): Set<Int>`** -- Copies IDs selected by any requested Tag group in full directional encounter order.
- **`getOutgoingEdges(id: Int, groups: Set<String>): Set<Int>`** -- Copies IDs selected by any requested Tag group in full directional encounter order.
- **`getEdges(src: Int, dst: Int, tag: String? = null): Set<Int>`** -- Copies pair IDs, optionally restricted to the complete tag; returns empty for missing endpoints or matches.
- **`findEdge(src: Int, dst: Int): Int?`** -- First pair ID, or null for missing endpoints or matches.
- **`findEdge(src: Int, dst: Int, tag: String): Int?`** -- First complete-triple ID, or null for missing endpoints or matches.

**Metadata**

- **`val metaNames: Set<String>`** -- All metadata property names.
- **`getMeta(name: String): IValue?`** -- Retrieve metadata value.
- **`setMeta(name: String, value: IValue?): Unit`** -- Set or delete (`null`) metadata.

**Lifecycle**

- **`clear(): Unit`** -- Remove all nodes, edges, and metadata.
- **`transferTo(target: IStorage): Map<Int, Int>`** -- Copy all data to target. `target` must be a different storage instance; raises `IllegalArgumentException` if same. Returns node ID mapping (source to target).
- Persistent backends (`MapDBStorageImpl`, `Neo4jStorageImpl` and their concurrent variants) implement `AutoCloseable`. Call `close()` to release resources. `IStorage` itself is not closeable.

**Concurrency**

- **`val criticalSectionLock: Lock?`** -- The lock `criticalSection` holds. Non-null on a thread-safe implementation, `null` on a single-threaded one.
- **`IStorage.criticalSection { ... }: T`** -- Runs the block atomically against every other operation on the same thread-safe storage and returns its result. Runs unguarded on a single-threaded one. Reentrant: a nested `criticalSection` on the same storage and thread proceeds.

### Implementations

- **`NativeStorageImpl(projection: AdjacencyProjection? = null, tagGroup: (String) -> String = { it })`** -- In-memory, single-threaded; omit the projection for ordinary storage.
- **`NativeConcurStorageImpl(tagGroup: (String) -> String = { it })`** -- In-memory, thread-safe.
- **`LayeredStorageImpl(frozenLayerFactory: () -> IStorage = { NativeStorageImpl() })`** -- Freeze-and-stack for phased pipelines. Thread-safe. The Frozen layer is read-only, so the default single-threaded factory stays safe.
- **`LayeredStorageImpl(projection: AdjacencyProjection?, frozenLayerFactory: () -> IStorage = { NativeStorageImpl() })`** -- Construct with one fixed projection; the factory-only constructor remains available to Kotlin and Java callers.
- **`LayeredStorageImpl(projection: AdjacencyProjection?, tagGroup: (String) -> String, frozenLayerFactory: () -> IStorage = { NativeStorageImpl(tagGroup = tagGroup) })`** -- Construct with fixed Tag group selection and the same default frozen grouping.
- **`AdjacencyProjection(edgeTag: String, kindProperty: String, keyProperty: String)`** -- Select exact adjacency by an edge tag and two fixed destination fields; configure it before creating rows.
- **`ExactAdjacencyStorage.getExactOutgoingEdges(source: Int, kind: IValue, key: IValue): Set<Int>`** -- Return matching physical edge IDs; requires a configured projection.
- **`ExactAdjacencyReads.getExactOutgoingEdges(source: Int, kinds: Set<IValue>, key: IValue): Set<Int>`** -- Selects the requested kinds in one operation.
- **`ExactAdjacencyStorage.attachExact(source: Int, target: Int, properties: Map<String, IValue> = emptyMap()): Int`** -- Reuse or create the projected relation; raises `IllegalArgumentException` for a conflicting target key.

### `LayeredStorageImpl`

- **`val layerCount: Int`** -- Number of layers (1 = active only, 2 = active + frozen).
- **`freeze(): Unit`** -- Merges the visible image into one Frozen layer and resets the Active layer.
- **`clearActiveLayer(): Unit`** -- Reverts temporary changes; frozen entities and their prior images reappear.
- **`bindPropertyFamilies(families: EdgePropertyFamilies): Unit`** -- Binds the immutable property family; raises `IllegalStateException` for an unequal rebind.
- **`getEdgeProperties(id: Int, layer: StorageLayer): Map<String, IValue>?`** -- Returns the selected complete image or null; `FROZEN` ignores visible deletion.
- **`getEdgeProperty(id: Int, name: String, layer: StorageLayer): IValue?`** -- Returns the selected named property; `ACTIVE` reads only explicit edits on a promoted Edge.
- **`hasActiveEdgeProperty(id: Int, name: String): Boolean`** -- True for an explicit edit, null removals included.

### External Backend Modules

- **`JgraphtStorageImpl`** -- JGraphT backend (module: `commons-graph-impl-jgrapht`).
- **`JgraphtConcurStorageImpl`** -- Concurrent JGraphT backend.
- **`MapDBStorageImpl`** -- MapDB persistent backend (module: `commons-graph-impl-mapdb`).
- **`MapDBConcurStorageImpl`** -- Concurrent MapDB backend.
- **`Neo4jStorageImpl`** -- Neo4j backend (module: `commons-graph-impl-neo4j`).
- **`Neo4jConcurStorageImpl`** -- Concurrent Neo4j backend.

## Configuration

- `NativeStorageImpl` accepts `projection: AdjacencyProjection? = null`; null selects ordinary Storage. `NativeStorageImpl` and `NativeConcurStorageImpl` accept `tagGroup: (String) -> String = { it }`.
- `LayeredStorageImpl` accepts `frozenLayerFactory: () -> IStorage = { NativeStorageImpl() }`, with an overload accepting `projection: AdjacencyProjection?`; its Frozen layer is read-only.
- Select the `LayeredStorageImpl` overload with `projection` and `tagGroup` for custom grouping; keep the function pure and fixed for the Storage lifetime.
- Configure projected destination fields before creating projected Edges and keep them unchanged while such an Edge exists.
- Bind an optional `EdgePropertyFamilies` declaration once, before or after import; unequal rebinding fails.

## Gotchas

- The typed reader/writer, `ArrayStorage`, schema keys and scoped cell readers in [Storage design](../design-storage.md#typed-storage-capabilities) are not available APIs; missing implementation is listed in [Storage Open Gaps](../design-gaps-storage.md#typed-storage-implementation).
- Compatibility outer-map copies do not freeze nested mutable `IValue` content; preserve ownership until the captured-snapshot boundary is implemented.

- Share one storage instance across threads only when `storage.criticalSectionLock != null`. `criticalSection` does not guard a single-threaded storage; two threads on one corrupt it.
- Each single `IStorage` call on a thread-safe storage is atomic. A sequence of calls is not. Wrap every check-then-add, read-modify-write, or read that decides a write in one `storage.criticalSection { }`.
- Graph operations and Label hierarchy operations are atomic on their thread-safe Storage. Labeled traversal sequences are lazy: each step is atomic, but the whole iteration is not. Wrap a group of operations or an iteration that must be atomic together (see [Graph API](graph.md)).
- A copy returned by a thread-safe storage is fixed at the call. Later writes, `freeze()`, and `clearActiveLayer()` do not change it.
- Never call a `suspend` function inside `criticalSection`. The coroutine can resume on another thread, which does not own the lock.
- Never wait inside `criticalSection` for another thread that uses the same storage (`Future.get()`, `CountDownLatch.await()`, `Thread.join()`, `runBlocking`, `awaitAll`). Both threads block forever.
- Take the locks of two storages in one fixed order on every thread. Nesting `a.criticalSection { b.criticalSection { } }` on one thread and the reverse on another deadlocks. So do `a.transferTo(b)` and `b.transferTo(a)` running at the same time.
- Revert listeners on `LayeredStorageImpl` run while the lock is held. A listener never blocks, may read the storage, and never writes it.
- A `RevertListener` gets one `RevertNotice(removed, restored, edgeStructuresBefore)` per revert (`clearActiveLayer()` and `clear()`), empty ones included. `removed` and `restored` are `StorageEntityIds(nodes, edges)`. A restored edge missing from `edgeStructuresBefore` has reappeared.
- Stop every thread that uses a persistent concurrent backend before calling `close()`.

- All graph-layer exceptions (`EntityNotExistException`, `EntityAlreadyExistException`, `InvalidPropNameException`, `FrozenLayerModificationException`) extend `GraphException`. Catch `GraphException` to handle any graph failure uniformly.
- `IStorage` IDs are auto-generated `Int` values. Never hard-code or predict them.
- `transferTo` remaps IDs. The returned `Map<Int, Int>` maps source IDs to new target IDs. `target` must be a different storage instance.
- A Tag group never changes complete-tag identity: grouping `write@1` as `write` does not make an exact lookup of `write` match it.
- Native directional reads preserve insertion order; layered reads place frozen rows before active-only rows, and property promotion retains frozen order.
- `deleteNode` cascades to all incident edges in the same storage.
- `setNodeProperties`/`setEdgeProperties` with `null` values delete those properties, not set them to null.
- `LayeredStorageImpl.freeze()` merges active + frozen into a new Frozen layer. Active layer properties overlay Frozen layer properties for the same entity.
- `LayeredStorageImpl` raises `FrozenLayerModificationException` when deleting a frozen node. Deleting a frozen edge masks it until a revert or freeze.

## Capability adapters

- **`StorageAccess(storage: LayeredStorage)`** — Takes ownership; exposes `reader`, `writer`, `compatibility` and idempotent `close()`.
- **`GraphReader.read(action: (StorageReadScope) -> R): R`** — Supplies a read-only scope; saved scopes and iterators expire at exit.
- **`GraphWriter.write(action: (StorageWriteScope) -> R): R`** — Supplies a write-only scope with compound exclusion, without callback rollback.
- **`GraphWriter.freeze()` / `clearActiveLayer()` / `clear()`** — Applies the existing layered lifecycle.
- **`StorageReadScope.getNodeIDs()` / `getEdgeIDs()`** — Returns fixed selected ID snapshots.
- **`StorageReadScope.getNodeProperties(id)` / `getEdgeProperties(id)`** — Returns detached fixed property maps.
- **`StorageReadScope.getIncomingEdges(id, group?)` / `getOutgoingEdges(id, group?)`** — Returns ordered iterators valid inside the callback.
- **`StorageWriteScope.addNode(properties)` / `addEdge(src, dst, tag, properties)`** — Captures values and returns storage IDs.
- Keep no direct access to the storage supplied to `StorageAccess`; close its owner after releasing every graph.
- Exit the read scope before writing, freezing, reverting, clearing, closing or acquiring a compatibility critical section; each attempt throws `IllegalStateException`.
- Use borrowed scopes on their entering thread only; copied property content and selected ID snapshots may escape.
- Reacquire integer entity IDs after `clear`; integers do not carry a stored-entity lifetime.

## Registered fields and cells

Construct `LayeredStorageImpl(StorageSchema(keys))` before `StorageAccess`. A `PropertyKey<T>` binds one compatibility name, runtime type and `PropertyCodec<T>`; the codec validates/captures immutable payloads and converts independent compatibility values. Registration is fixed at construction.

- `read.getNodeProperty(id,key)` and `read.getEdgeProperty(id,key,layer)` return optional immutable payloads without a codec cycle. Required `getNodeInt`, `getNodeLong`, `getEdgeInt` and `getEdgeLong` reject absence rather than returning zero.
- `write.setNodeProperty(id,key,value)` and `write.setEdgeProperty(id,key,value)` capture before publication.
- `IndexedPropertyKey<T>` registers one anchor, cell prefix and opaque pair-address codec. `read.edgeCells(id,key,layer).lookup(first,second)` selects one payload without enumerating the directory; `members()` returns fixed membership. `write.setEdgeCell` captures the changed payload and publishes membership/cell together.
- `PropertyValue.capture(key,value)` admits a typed payload. `membership(key,values)` admits fixed family membership; `legacy(value)` captures an extension value. A retained value supports typed `get(key)`, `members(key)` and independent compatibility `snapshot()`.
- `getNodeContents`/`getEdgeContents` return fixed maps of admitted values; named `getNodeContent`/`getEdgeContent` select one property. `setNodeContents`/`setEdgeContents` validate the complete update before mutation and retain already admitted payloads without recapture. `captureNodeContents`/`captureEdgeContents` and `validateNodeContents`/`validateEdgeContents` prepare caller-owned buffered writes without publishing them.

An escaped payload or property-content map retains no mutable row, directory or borrowing scope. A borrowed cell reader expires at callback exit. Family selection and explicit deletion retain the layered contracts; full compatibility snapshots pay for their requested values. Schema meaning and reference interpretation belong to the caller.
