# Glossary

Established vocabulary of commons-graph. Every term names one concept, and a concept named here is referred to only by that name. This file routes to the entry files and holds no entry.

## Conventions

Source locations are relative to `commons-graph/src/main/kotlin/edu/jhu/cobra/commons/graph/`. A Source that names a document starts at the repository root.
