# Storage property families

`EdgePropertyFamilies(edgeTag, memberPrefix, anchorName)` is one immutable declaration. A property belongs to it when its edge has the declared tag and its name equals the anchor or starts with the member prefix. The nullable `anchor(tag, name)` extension owns that classification; NONE is null. No declaration list, callback, registry or mutable member is stored in the value.

`IStorage.bindPropertyFamilies(families)` is a construction operation. Flat stores inherit its no-op default; delegating stores forward it. `LayeredStorageImpl` binds under its write lock: an absent declaration is assigned once, an equal tuple is an unchanged success, and a different tuple throws `IllegalStateException` without changing storage. Binding may precede or follow ordinary data import, and performs no row inspection or migration. Freeze, clear and rollback do not remove the declaration. A newly opened storage binds independently.

`LayeredEdgeReads` exposes the nullable declaration, a layer-selected point read, and `hasActiveEdgeProperty(id, name)`, which distinguishes an explicit null edit from no edit. Existing constructors remain available; the non-null declaration overload configures the same owner slot without making the nullable projection overload ambiguous. The storage owner and its stable accessor are described in [Storage](design-storage.md#layeredstorageimpl).

On a promoted edge, an explicit anchor edit makes that family belong to ACTIVE. A visible member reads its explicit ACTIVE edit, or absence when its anchor is explicitly active, otherwise the frozen property. Later anchor writes do not reset other ACTIVE members. Whole-row composition and freeze use the same `ActiveLayer.composePromotedEdgeProperties` fold: while already copying frozen properties, omit members whose anchors have explicit active edits, then apply every active edit, null removals included. Nonfamily properties keep sparse fallback. ACTIVE ownership exists only in the sparse edits; rollback drops ownership with those edits.

Binding compares one fixed tuple, independently of graph size. Classification uses one tag comparison, anchor comparison and prefix check, with string work bounded by the addressed key and declaration lengths. Point selection adds one anchor lookup. Whole-row composition captures the declaration once and adds constant classification work per property already visited; freeze physically retains only the composed survivors. No state grows with edges, labels, writes or buffer segments.
